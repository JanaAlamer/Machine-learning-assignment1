Features Description 

Company: Laptop brand 

TypeName: Type of laptop 

Inches: Screen size 

ScreenResolution: Screen details 

Cpu: Processor type 

Ram: RAM size 

Memory: Storage type 

Gpu: Graphics card 

OpSys: Operating system 

Weight: Laptop weight 

Price: Laptop price 

Purpose of Using This Dataset 

This dataset was selected because it provides real-world data related to laptop specifications and pricing, which is highly relevant to artificial intelligence applications. Analyzing such data helps in understanding patterns and relationships between features, which is a fundamental step in building machine learning models. This dataset can be used in the future for tasks such as price prediction, recommendation systems, and feature importance analysis, making it directly connected to the field of artificial intelligence.
